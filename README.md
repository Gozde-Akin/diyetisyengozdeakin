## Stack

- Next.js 16 + React 19 + TypeScript
- Tailwind CSS 4
- next-intl (6 languages: TR, EN, DE, FR, RU, AR)
- Framer Motion

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
